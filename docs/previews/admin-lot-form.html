What the kind switch actually does
  • Shows one detail section and hides the other. Not disabled — hidden, so the form never carries a VIN on a pallet.
  • Changes which fields are required. Year is required on a vehicle and does not exist on goods.
  • Does not change the shared fields. Title, city, condition, pricing and auction timing are identical for both.
Why sections are visibly marked, not just hidden
  • The greyed-out Goods detail panel with a HIDDEN marker is a deliberate choice. A section that silently vanishes reads as a form bug.
  • Staff learn which sections belong to which kind without memorising it.
  • The same marker pattern is already used on the operations console's severity pills, so the two surfaces read as one product.
